# Inkwell

Read the Founders' handwriting: photograph an 18th-century letter and Inkwell transcribes it, modernizes it, explains the people and places it mentions, and reads it aloud with word-by-word highlighting.

Built at &hacks XII (William & Mary). **The app lives in [`inkwell/`](inkwell/)** — see [`inkwell/README.md`](inkwell/README.md) for features, setup, evaluation, and credits.

## Disclosure: pre-event prototype
